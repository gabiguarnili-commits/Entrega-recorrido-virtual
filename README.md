# Entrega-recorrido-virtual
Entrega 3 
Mi proceso para esta entrega fue largo, queria hacer una pagina bonita y sencilla pero que se entendiera la serie y los estilos de las protagonistas. Al incio ya entendia un poco el leguage que se manejaba y entendia para que servia crear distintos html, o css, sabia como cambiar el fondo y poner minimas animaciones, para el recorrido virtual queria que tuvieras mas cosas, entonces con mucha ayuda de la ia y del internet, me pude insipirar e ir acomodando todo. Lo que mas se me dificulto fue poner las animaciones, y el audio ya que no sabia como plasmar mis ideas en la pagina pero al final me gusto mucho el resultado. 
Algunas dificultades que tuve son:
1.Los espacios que se quedaban en los nombres de los archivos y cuando estaba escribiendo el código.
2.Ajustar las imagenes para que quedaran de una manera especifica. 
3.Saber como poner las animaciones, jugar con el tiempo, colores y distintos aspectos.
4.Entender como hacer que la pagina fuera interactiva.
